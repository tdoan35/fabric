About Event
​Kick off SF Tech Week with 200 hackers to finally build your own custom personal agent.

​Sunday, October 4, 2026 · Terra Gallery, San Francisco

​Automate the boring stuff. Build an agent to manage your inbox, control your smart home, help you with day-to-day decisions and tasks, manage your relationships... ok maybe not that one.

​The Challenge
​Build a personal agent that helps you or your team with something in your personal life. It can do one thing really well or help across several parts of your day.

​Hack solo or in a team of up to five people. You’re welcome to use tools from any of the co-hosts, but it’s not required.

​The Stack (Co-Hosts)
​On site for the hackathon:

​Neon: backend, including AI Gateway and Postgres

​Mastra: agent framework, observability and factory

​Exa: web search and crawling

​Fly.io: sprites agent sandboxes

​Kernel: browser automation and use

​Executor (YC): tools and MCP gateway for your agent

​Assistant UI (YC): UI components for agent chat

​AgentMail (YC): email inboxes for your agents
